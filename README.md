# amagi

Cuentas claras para salidas en grupo.

## Características

- Agrega participantes a tu salida.
- Carga gastos y especifica quién pagó y quiénes participaron de cada gasto.
- Calcula automáticamente los saldos y las transferencias necesarias para saldar deudas.
- Genera un resumen compartible como imagen.

## Desarrollo

### Requisitos

- Node.js

### Instalación

```bash
npm install
```

### Ejecución en modo desarrollo

```bash
npm run dev
```

### Construcción para producción

```bash
npm run build
```
